ClashBarPlus 是基于 [mihomo](https://github.com/MetaCubeX/mihomo) 的原生 macOS 菜单栏代理客户端，使用 SwiftUI + AppKit，面向轻量、稳定与可观测的日常使用。

## 与上游的关系

ClashBarPlus 是 [Sitoi/ClashBar](https://github.com/Sitoi/ClashBar) 的 fork，基线为上游 **v0.3.3**，核心实现全部来自上游，这里只做增量改动并持续同步上游更新。

- **版本号**自 `v1.0.0` 起独立编号，不跟随上游的 `v0.3.x` 序列
- **只通过 GitHub Releases 分发 DMG**，不提供 Homebrew 安装
- **Bundle ID、数据目录与特权助手标签与上游保持一致**，因此覆盖安装是原地升级，既有配置、订阅、设置与登录项授权全部保留

<Callout type="warn" title="不能与原版并存">
  由于 Bundle ID 相同，ClashBarPlus 与原版 ClashBar
  不能同时安装。若此前通过 Homebrew 安装过上游版本，请先执行 `brew uninstall --cask clashbar`。
</Callout>

与上游的差异记录在[更新日志](/docs/changelog)；v0.3.3 及更早的历史见[上游 CHANGELOG](https://github.com/Sitoi/ClashBar/blob/main/CHANGELOG.md)。

## 设计初心

围绕两个关键词：**轻量** 与 **稳定**。

- **轻量化优先**：在打包 mihomo Core 的前提下，应用体积目标控制在 **15 MB 以内**。
- **可裁剪交付**：移除 Core 后，应用体积目标控制在 **3 MB 以内**，便于快速分发。
- **稳定性优先**：优先保证日常可用性与长期运行稳定，避免为短期功能堆叠牺牲可靠性。

首次安装见 [快速开始](/docs/quick-start)；完整产品能力见 [功能总览](/docs/features)；排障见 [常见问题](/docs/troubleshooting)。

| 客户端                  | 应用体积 |
| ----------------------- | -------: |
| ClashBarPlus.app（No Core） |     3 MB |
| ClashBarPlus.app（含 Core） |  14.2 MB |
| ClashMac.app            |  75.2 MB |
| Clash Verge.app         | 128.4 MB |
| Clash Party.app         | 496.7 MB |
| Sparkle.app             | 519.8 MB |

<Callout type="info" title="数据说明">
  对比数据来自同一台 macOS 环境下 Finder
  显示值。不同版本与构建方式会影响最终体积，以上用于说明轻量化设计方向，而非严格性能基准。
</Callout>
